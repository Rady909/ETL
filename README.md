 # AUPP – ETL Robotics & AI Showcase

Standby showcase slide for the **AUPP Emerging Technology Lab (ETL)** at the **FrancoTech Experience Zone (EX-09)**, converted from PowerPoint to a single HTML page.

- XGO Mini Robot: hand-gesture and VR control (Python 3)
- TurtleBot 4: ROS 2 LiDAR SLAM navigation with YOLO human detection and following
- TurtleBot 3: ROS 2 SLAM and live RViz mapping

## View it

Open `index.html` in any browser (Chrome/Edge recommended). The slide scales to fit the screen and the three videos autoplay and loop. Press **F** for fullscreen.

Live site (after enabling GitHub Pages): `https://<your-username>.github.io/aupp-etl-showcase/`

## Structure

```
index.html      the slide
assets/         logo, looping videos (.mp4) and poster frames (.jpg)
```

The original GIFs (about 31 MB) were converted to muted looping MP4s (a few MB) so the page loads fast.
